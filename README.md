# HH Cover Letter Studio

Небольшой локальный сервис для подготовки персональных сопроводительных писем под вакансии на hh.ru. Он получает описание вакансии и **ваш подтверждённый** профиль, а затем просит OpenAI подготовить черновик письма.

Сервис не входит в hh.ru, не хранит резюме и не отправляет отклики сам. Это специально: письмо остаётся у вас для проверки и ручной отправки. Так можно исправить неточность до того, как её увидит рекрутер.

## Ассистент откликов

При первом запуске нажмите «Включить и настроить». Доступны три режима:

- **Только черновики** — сервис генерирует сопроводительное письмо, а заявку вы отправляете сами.
- **Очередь на подтверждение** — рекомендуемый стартовый режим: будущая интеграция подберёт вакансии и подготовит письма, но каждый отклик останется на вашем подтверждении.
- **Автоподача по строгим правилам** — режим появится после отдельного подключения официального канала hh.ru. В нём обязателен дневной лимит и учитываются позиции, география, минимальная зарплата, нужные и исключающие ключевые слова.

Параметры режима и очередь сохраняются только в `localStorage` браузера на вашем компьютере. Даже после подключения hh.ru эта версия не отправляет отклики: она только показывает вакансии, формирует письмо и собирает очередь на ваше подтверждение.

### Подключение hh.ru

1. Создайте OAuth-приложение в кабинете разработчика hh.ru и задайте redirect URL `http://localhost:8080/auth/hh/callback`.
2. Скопируйте `.env.example` в `.env` и заполните `HH_CLIENT_ID`, `HH_CLIENT_SECRET` и контакт в `HH_USER_AGENT`. Секреты остаются только в `.env` и не попадают в Git.
3. Запустите приложение, нажмите «Подключить hh.ru» и завершите вход в своём аккаунте.
4. В настройках ассистента укажите запрос и, при необходимости, числовой ID региона hh.ru. Нажмите «Найти вакансии», выберите подходящую, сформируйте письмо и добавьте её в очередь.

OAuth-код обменивается сервером на токен через `https://api.hh.ru/token`; токен хранится локально в `data/hh-token.json` с доступом только владельцу. API hh.ru использует OAuth2 и требует `HH-User-Agent`; перед добавлением реальной отправки отклика нужно сверить доступные вашему приложению права в их [официальной документации](https://api.hh.ru/openapi/redoc).

## Запуск

Нужны Go 1.22+ и ключ OpenAI API.

```bash
cp .env.example .env
set -a; source .env; set +a
go run ./cmd/app
```

Откройте `http://localhost:8080`. В первом поле вставьте актуальную выжимку из резюме, во втором — полный текст вакансии. Нажмите «Сгенерировать письмо», проверьте результат и только затем вставьте его в отклик на hh.ru.

`OPENAI_API_KEY` должен находиться только в локальном окружении. Файл `.env` уже исключён из Git. Приложение вызывает `POST /v1/responses` с `store: false`; API принимает текстовые входные данные и возвращает текстовый ответ. См. [официальный справочник OpenAI Responses API](https://developers.openai.com/api/reference/cli/resources/responses/methods/create).

## API для n8n

После запуска сервиса импортируйте [`n8n/cover-letter-webhook.json`](n8n/cover-letter-webhook.json) в n8n. Он принимает POST-запрос на webhook и пересылает поля `candidate_profile` и `vacancy_text` в сервис.

Для n8n на том же компьютере оставьте адрес `http://host.docker.internal:8080/api/letter` (Docker Desktop). Если n8n запущен без Docker, измените его на `http://localhost:8080/api/letter`. Активируйте workflow только после этой настройки.

Пример запроса:

```json
{
  "candidate_profile": "Проверенные факты из моего резюме…",
  "vacancy_text": "Полное описание вакансии…"
}
```

В ответе придёт `{ "letter": "…", "model": "…" }`.

# Reply Studio

Локальное приложение для подготовки сопроводительных писем к вакансиям на hh.ru. Оно не использует AI-ключи, не хранит резюме на сервере и не отправляет отклики без вас.

## Как пользоваться

1. Откройте приложение и вставьте 3–6 проверенных предложений о себе: роль, стек, проект и результат.
2. Вставьте ссылку вида `https://hh.ru/vacancy/...`. Письмо соберётся автоматически.
3. При желании добавьте название позиции или требования — это делает обращение точнее.
4. Нажмите «Копировать» либо добавьте черновик в очередь. Кнопка «Открыть и скопировать» откроет hh.ru, но окончательное решение об отклике и отправку всегда оставляет за вами.

Профиль и очередь находятся только в `localStorage` браузера на этом устройстве.

## Поиск вакансий

Встроенный поиск удалён намеренно: официальный API hh.ru на этой сети возвращает защитную блокировку для серверных запросов. Приложение не обходит капчу или защиту hh.ru. Найдите вакансию обычным способом на hh.ru и вставьте её ссылку в Reply Studio.

## Запуск

Нужен Go 1.22+.

```bash
cp .env.example .env
go run ./cmd/app
```

Откройте [http://localhost:8080](http://localhost:8080).

`.env` уже исключён из Git. В нём можно изменить `APP_ADDR`, если порт 8080 занят.

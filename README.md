# HH Cover Letter Studio

Небольшой локальный сервис для подготовки персональных сопроводительных писем под вакансии на hh.ru. Он получает описание вакансии и **ваш подтверждённый** профиль, а затем собирает письмо по локальному шаблону.

Сервис не входит в hh.ru, не хранит резюме и не отправляет отклики сам. Это специально: письмо остаётся у вас для проверки и ручной отправки. Так можно исправить неточность до того, как её увидит рекрутер.

## Ассистент откликов

При первом запуске нажмите «Включить и настроить». Доступны три режима:

- **Только черновики** — сервис собирает сопроводительное письмо по шаблону, а заявку вы отправляете сами.
- **Очередь на подтверждение** — рекомендуемый режим: приложение подберёт вакансии и подготовит письма, но каждый отклик останется на вашем подтверждении.
- **Автоподача по строгим правилам** — недоступна для аккаунтов соискателей: перед откликом всегда требуется ваше действие в hh.ru.

Параметры режима и очередь сохраняются только в `localStorage` браузера на вашем компьютере. Приложение не получает пароль hh.ru и не отправляет отклики: оно показывает вакансии, формирует письмо и собирает очередь на ваше подтверждение.

### Публичный поиск hh.ru

1. Скопируйте `.env.example` в `.env` и укажите контакт в `HH_USER_AGENT`.
2. Запустите приложение и в настройках ассистента укажите запрос и, при необходимости, числовой ID региона hh.ru.
3. Один раз вставьте проверенную выжимку в поле «Мой профиль» и нажмите «Сохранить профиль». Она останется только в браузере этого компьютера.
4. После этого достаточно вставить ссылку на вакансию hh.ru: письмо соберётся автоматически. Текст вакансии можно добавить вручную, если хотите уточнить детали.
5. Когда будете готовы, нажмите «Одобрить и открыть hh.ru»: письмо скопируется, а вакансия откроется в новой вкладке. Перед отправкой проверьте текст и нажмите финальную кнопку отклика самостоятельно.

Публичный поиск выполняется через `GET /vacancies` официального API с обязательным `HH-User-Agent`. hh.ru может запросить капчу для неавторизованного поиска; в этом случае приложение не обходит её и просит продолжить поиск вручную. Поддержка API для соискателей прекращена, поэтому в приложении нет OAuth-авторизации и автоматической отправки откликов. См. [официальную документацию hh.ru](https://api.hh.ru/openapi/redoc).

## Запуск

Нужен Go 1.22+. Ключи внешних AI-сервисов не требуются.

```bash
cp .env.example .env
set -a; source .env; set +a
go run ./cmd/app
```

Откройте `http://localhost:8080`. В первом поле вставьте актуальную выжимку из резюме, во втором — полный текст вакансии. Нажмите «Сгенерировать письмо», проверьте результат и только затем вставьте его в отклик на hh.ru.

Письмо создаётся локально: заголовок берётся из первой строки вакансии, а первая фраза профиля — дословно как подтверждённый релевантный опыт. Так сервис не придумывает факты и не расходует AI-лимиты. Файл `.env` уже исключён из Git и нужен только для настройки адреса приложения и заголовка публичного API hh.ru.

## API для n8n

После запуска сервиса импортируйте [`n8n/cover-letter-webhook.json`](n8n/cover-letter-webhook.json) в n8n. Он принимает POST-запрос на webhook и пересылает поля `candidate_profile` и `vacancy_text` в сервис.

Для n8n на том же компьютере оставьте адрес `http://host.docker.internal:8080/api/letter` (Docker Desktop). Если n8n запущен без Docker, измените его на `http://localhost:8080/api/letter`. Активируйте workflow только после этой настройки.

Пример запроса:

```json
{
  "candidate_profile": "Проверенные факты из моего резюме…",
  "vacancy_text": "Полное описание вакансии…"
}
```

В ответе придёт `{ "letter": "…", "source": "local_template" }`.
